Original Paper Adventure diagrams. Seven reviewed PNGs are deterministic raster snapshots of art.mjs + game.json. manifest.json binds each PNG and LF-normalised generated SVG by SHA256. build.mjs verifies both before copying; changed art must be rasterised, reviewed and rebound explicitly. No third-party story or art. The raster snapshots allow the release build to run without a browser or network image service.
