PA Classroom Sans: independent classroom-only subset and 400/700 instances of the same OFL source, renamed PAClassroomSans; original PA Free Game Sans files retained byte-for-byte.

PA Home Sans: independent Home v2 OFL subset and 400/700 instances of Noto Sans SC, renamed PAHomeSans. Previous PA Free Game Sans and PA Classroom Sans artifacts retained.

PA Ocean Sans: independent Ocean Classroom Chinese edition subset and 400/700 instances of the same Noto Sans SC OFL source, renamed PAOceanSans. Built by scripts/prepare_ocean_chinese_fonts.py. Existing font files retained byte-for-byte. Licensed under SIL Open Font License 1.1; see OFL.txt.

PA Museum Sans: independent 400/700 Noto Sans SC OFL subsets for paired museum editions. Renamed PAMuseumSans by scripts/prepare_museum_fonts.py. Existing font files unchanged. SIL OFL1.1, see OFL.txt.

PA Library Sans Regular/Bold: renamed subsets of Noto Sans SC under SIL Open Font License. Original C:/Windows/Fonts/NotoSansSC-VF.ttf; generated by scripts/prepare_library_fonts.py for the C09 bilingual edition. Existing game font files remain unchanged.
