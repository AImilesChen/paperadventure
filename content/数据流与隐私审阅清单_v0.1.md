## 已运行的技术预览

| 数据或服务 | 当前行为 | 不能推断的事项 |
| --- | --- | --- |
| 公开页面与 Cloudflare | 静态、noindex 的 Cloudflare Worker 预览提供页面与资源；浏览器请求必然产生网络访问数据 | 具体日志字段、地域、保存期及子处理者尚未核实 |
| 本机草稿与偏好 | 创建器、偏好及反馈草稿可能保存在访问者浏览器的 localStorage；无真实订单或跨设备账号 | 用户清除浏览器数据后的恢复能力不能承诺 |
| 四种分析脚本 | GA4、Clarity、Ahrefs Web Analytics、Plausible 的公开 ID 已写入代码，`VITE_ANALYTICS_RELEASED` 未开启，预览不加载其脚本 | 不能据此声称分析平台在未来不会收集页面 URL、设备/网络信息或 Clarity 会话记录 |
| 分析偏好控制 | 预备代码用独立的 v2 localStorage key 保存允许/拒绝；仅公开资料页可加载，创建、结账、账号、订单及私有支持页被排除 | 需要上线环境逐一测试拒绝、允许、撤回、跨页跳转、浏览器阻拦和第三方实际行为 |
| 客服邮箱 | `support@paperadventure.app` 已做发信、收信及回复诊断；邮箱界面为 `mail.aicareertest.work` | 邮件存储位置、访问人员、保存期及删除流程尚待确认 |

| --- | --- | --- | --- |
| 成人邮箱验证 | 邮箱用于发一次性链接；D1 存邮箱哈希、挑战与限流记录；会话为 HttpOnly SameSite Cookie | 计划用 Resend 发登录/交付邮件；尚未配置 | 发信服务与现有 Cloudflare 邮箱是否共用、真实发送身份、运营访问权限 |
| 购买与交付 | D1 存商品/价格/许可版本、故事设定、邮箱哈希、支付状态、权限及问题单；Stripe Checkout 接收成人邮箱和结账信息 | Stripe；私有 R2 存玩家包和成人指南 | 商户主体、销售地税费、订单/文件/退款/问题单保存期与删除例外 |
| AI 提案及定制活动 | 成人输入的主题想法、年龄范围、人数和活动设置计划发送至 DeepSeek；D1 记录活动、修改请求及模型用量，R2 存生成物。OpenAI 仅保留为显式可选代码路径，当前未启用 | DeepSeek API（拟采用） | 模型与供应商设置、提示词/输出的实际保存方式、删除/修正流程；界面不应索取儿童姓名或照片 |
| 客户支持与纠错 | 已验证购买者的订单关联问题描述存 D1；反馈表提示不要填儿童姓名或照片 | 运营人员及相关邮件服务 | 人员权限、敏感信息误填处理、问题单保存期 |
| 分析上线后 | 仅访客选择允许后，预定在公开资料页加载四供应商脚本，发送页面和受限事件；不发送表单文本或故事设定的自定义事件 | Google、Microsoft、Ahrefs、ShipSolo 托管的 Plausible | 各供应商实际配置、地域/跨境传输、保留期、同意适用方式与撤回效果 |

源码已设置：邮箱登录链接 15 分钟、会话 7 天；过期挑战和限流记录有定时清理，成人草稿提供自行删除入口。这些**不是**订单、生成文件、问题单、邮件或分析数据的统一保存期。上述其他期限未决，不应在正式隐私页填入猜测值。

## 发布前逐项核对

1. 确认商户/数据控制者名称、公开联系地址、客服渠道与实际服务区域。
2. 在 Cloudflare、邮件系统、Stripe、DeepSeek（或最终启用的 AI 供应商）、四种分析工具的真实配置中记录数据类别、用途、地域、访问权限、保存期、删除方法与供应商条款。
3. 实测访客拒绝与撤回时没有非必要脚本；逐条确认哪些页面、事件与 URL 被第三方收到。
4. 制定成人草稿、订单、私有 PDF、生成记录、支持邮件/问题单的删除与保留规则；实现并测试可执行的请求流程。
5. 据实重写并审查 Privacy、Cookies、Terms、Refunds 四页和结账确认文案，再决定是否发布法律版本。没有上述证据前保持分析、销售与公开下载关闭。
