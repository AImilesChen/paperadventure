# Paper Adventure｜课堂独立主题世界重设计方案 v1.5

日期：2026-10-10。状态：**产品与内容设计方案，尚未替换线上商品**。本方案响应所有者对家庭与课堂目录高度重复、难以看出价格差异的反馈。它在内容制作完成前不得被当作已发布游戏或可下载 PDF。

## 1. 结论与边界

保留已经确认的免费权益：Celebration 的 Home H01 与 Classroom C01 继续作为两款不同的免费试玩游戏。这是唯一共用的主题世界。五款付费 Home 游戏仍在 Dinosaur、Space、Forest、Halloween、Christmas 世界；五款付费 Classroom 游戏改为下表中的**五个独立世界**。因此两个入口各有六款游戏，付费部分不再复用世界、封面或故事；全站是 11 个世界、12 款基础游戏。

课堂新世界必须有独立五关因果链、角色与小组协作机制、学生包、教师指南、A4 与 US Letter 文件、封面与缩略图。不能把旧 C02–C06 文件替换标题或插画后作为新商品。现有旧课堂包版本与测试订单保持可追溯，历史下载授权不可被新内容覆盖。原 C05/C06 的节庆措辞变体随旧版本保留，不计作新世界。

课堂版较家庭版贵 US$5 的说明应建立在**一位购买教师的授课班级使用许可、分组材料、教师引导与核对指南**上；独立世界增强选择价值，但不能单独被宣传成涨价理由。现有标价不因本次题材变化自动改变。

## 2. 课堂五个付费世界：先设计再制作

以下英文名和故事是内容蓝图的工作标题。每关列出获得的线索及其在下一关的用途；正式谜底、候选卡与答案数据须在各世界的独立内容源中冻结。

| 新世界与目录短名 | 课堂故事与目标 | 五关因果骨架 | 分组方式与视觉方向 |
| --- | --- | --- | --- |
| **Ocean Research Ship**（Ocean） | *The Coral Chart Expedition*：学生协作修复一张虚构海域的研究路线图，完成船长的纸上报告。 | ① 航海日志找调查点编号 → ② 用编号在海图定位 → ③ 各组比较不同观察卡，确认正确航道 → ④ 按航道排列调查记录 → ⑤ 合成完整报告。 | 观察员、地图员、记录员各持部分证据；蓝绿海图、研究船与珊瑚图形，不复用 Space 的火箭和星图。所有事实仅来自游戏纸张，不考真实海洋知识。 |
| **Museum of Curious Objects**（Museum） | *The Mixed-Up Exhibition*：展厅标签被调换，学生根据纸质证据恢复一场虚构展览。 | ① 找出标签上的展厅标记 → ② 按标记走展厅路线 → ③ 对照不同组的保管记录 → ④ 确定展品与说明卡的对应 → ⑤ 排成开馆展示表。 | 各组持不同“策展记录”，需要口头交换；暖黄展厅、展柜、编号卡。展品为虚构物，避免不准确的历史/文化归属。 |
| **Storybook Library**（Library） | *The Missing Final Chapter*：一本虚构故事书缺了结尾，学生找回页序并重建故事线索。 | ① 目录符号找书架 → ② 书架代码找页组 → ③ 各组角色线索确定事件顺序 → ④ 顺序解出最后一页位置 → ⑤ 合作完成结尾卡。 | 每组掌握不同角色视角，必须合并信息；书架、纸页、墨水与彩色书签。任务是阅读与排序，不要求学生透露真实家庭经历。 |
| **Weather Observatory**（Weather） | *The Lost Forecast Bulletin*：观测站的纸上预报记录散乱，学生帮助站长还原发布顺序。 | ① 观测标志选日期栏 → ② 日期栏指向地图格 → ③ 各组比较云、风、雨的虚构符号卡 → ④ 按共同规则排成预报序列 → ⑤ 完成站内公告。 | 各组负责一种符号，必须联合判断；柔和天空色、观测塔、纸风向标。符号规则在文件内完整给出，不假称真实气象预测。 |
| **Inventors' Paper Workshop**（Workshop） | *The Great Blueprint Relay*：纸上装置的设计页散落，各组把零件和操作次序拼回一张安全的展示蓝图。 | ① 零件清单找设计代号 → ② 代号找对应纸图 → ③ 各组约束卡排除错误组合 → ④ 确定操作顺序 → ⑤ 合并蓝图与展示说明。 | 设计员、检查员、讲解员互持信息；齿轮形纸卡、蓝图线条、明亮工作台。只有纸上想象装置，不要求电池、工具或真实机械制作。 |

每个世界须另写可测试的五关数据：`state_before`、所需事实、玩家动作、唯一答案、产出事实、下一关使用位置、三级提示、跳关补发、教师核对与结局。不能用本表的故事梗概代替完整玩家材料。

## 3. 网站信息架构与卡片设计

- `/en/for-home/` 显示 Celebration 免费游戏和五个 Home 世界，卡片以**具体游戏标题**为主、世界名为次；页头写“6 Home adventures”。
- `/en/for-classroom/` 显示 Celebration 免费游戏和上述五个新 Classroom 世界，卡片以课堂任务标题为主；页头写“6 Classroom adventures”。五款付费卡使用独立封面和课堂任务场景，不再出现家庭版的恐龙、火箭、森林、南瓜或圣诞树主图。
- `/en/themes/` 按 Home 与 Classroom 分组，不再把所有卡片强塞到“每个世界都有两个场景”的模式。Celebration 作为共用的免费世界，在两个分组内都清楚指向各自不同的文件；不要用“12 themes”虚增主题数。
- 卡片依次呈现：故事标题 → 世界标签 → 一句具体任务 → 场景/组织方式 → 包含的材料与当前状态 → 唯一主行动。不要让“Stripe test pack”标识压过故事差异。主题详情页保留版本、纸张、许可及状态说明。
- 数据结构改为“世界 `world_id` → 独立游戏 `adventure_id`/`setting` → 不可变 `pack_version`/文件清单”，不能再要求每个世界都同时拥有 Home 与 Classroom 子对象。新课堂世界使用新的稳定 ID，绝不复用 `dinosaur/classroom` 等旧 ID 绑定新文件。

## 4. 发布与迁移顺序

1. 为五个新课堂世界逐一冻结详细蓝图、答案数据、纸卡和教师组织流程；制作与剧情一致的独立封面。先完成一款端到端样板，再复用**制作流程**，不复用谜题答案。
2. 每款导出学生包和教师指南的 A4/US Letter 四份文件，做五关引用、唯一答案、PDF 版式和文件哈希核查。真人课堂试玩、实际彩色/灰度打印、素材权利与商品文案审查仍是正式成品门槛。
3. 前后端先支持新世界与旧版本并存、旧订单继续读取所购版本；新包准备好后逐款替换公开目录中的旧付费课堂卡。不要让尚未完成的新世界出现可购买按钮，也不要把旧 PDF 交付给新世界订单。
4. 替换完成后检查：首页滚动区、两个场景目录、全部主题页、价格页例子、AI 定制世界选择、站点地图、搜索索引、内部链接、购物车/订单快照、授权和下载。旧主题课堂 URL 保留清楚的停售/历史版本状态或适当重定向，不能静默改成另一款游戏。

**当前上线边界：**现有家庭/课堂付费包仍处 Stripe 测试流程。新课堂世界只是规划，不构成商品库存。任何“不同世界已上线”声明必须以新内容、独立封面、四份完整 PDF 和对应下载订单联调为依据。
