# Dinosaur｜恐龙主题设计蓝图

**状态：**H02/C02 仅有 PRD 故事方案；未制作可玩的完整资料包。**视觉：**原创、友好的小恐龙，脚印轮廓、纸地图、营地标识和研究档案；避免写实危险地形与伪科学标签。所有解题所需特征印在卡上。

| | H02 Home — The Little Dinosaur’s Way Home | C02 Classroom — The Dinosaur Research Station Mix-up |
|---|---|---|
| 任务 | 帮小恐龙沿纸上路线安全回到唯一营地 | 小组整理混乱的研究站记录，提交有证据的路线结论 |
| 1 分类 | 对照观察卡选对应脚印；获得路线标记 | 分类观察图卡；确定待整理档案集 |
| 2 定位 | 用标记拼地图；获得可走路径与检查点 | 足迹与给定特征配对；获得区域标记 |
| 3 合作 | 合并玩家手中的物资条件，选纸质补给卡；获得检查点代号 | 角色卡合并地点约束；确定观察区域 |
| 4 排序 | 查已给路标表，得最后路线与入口特征 | 按明示规则排时间条，形成路线记录 |
| 5 证实 | 用脚印、路线和入口条件选唯一营地卡 | 填观察结论与证据，教师核对后展示结局 |

**制品设计：**H02 玩家包为脚印/观察、拼接地图、分持补给条件、路标表、候选营地、欢迎卡；Host Guide 标注每张卡何时发、唯一营地答案和跳关后需补交的代号。C02 以每组档案袋为单位：观察图卡、脚印特征、分角色地点条件、时间条、研究结论单；Teacher Guide 列组数复制方式、证据核对、角色合并和简短复盘。两版各有 A4/US Letter，灰度区分靠轮廓与编号。

**设计边界：**这是虚构故事，不声称恐龙知识教学或科学准确性；不要求野外搜集、触摸/食用植物、真实露营或危险移动。家庭的“找路”与课堂的“整理证据”要保持不同成就感。制作时先固定唯一营地/区域和约束表，再写旁白、三级提示与答案。

**视觉/交互制作规格：**封面以小恐龙、足迹和安全营地为三层纸片，不画危险追逐；网页卡片突出“找路”，课堂细节页再展示“整理档案”的差异。脚印至少靠脚趾数、脚跟轮廓和缺口位置区分，不能仅凭绿色深浅。地图条有明显起止接口和字母，营地候选保留文字条件；研究站材料使用档案袋、时间条和证据单样式。插画为故事提示，关键信息仍以印刷清楚的卡表为准。
