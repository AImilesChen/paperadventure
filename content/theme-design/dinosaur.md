# Dinosaur｜恐龙主题设计蓝图

**状态：**H02/C02 已有先行蓝图与内部 PDF 初稿，尚待真人试玩和实物打印。**视觉：**原创、友好的小恐龙，脚印轮廓、纸地图、营地标识和研究档案；避免写实危险地形与伪科学标签。所有解题所需特征印在卡上。

| | H02 Home — The Little Dinosaur’s Way Home | C02 Classroom — The Dinosaur Research Station Mix-up |
|---|---|---|
| 任务 | 帮小恐龙沿纸上路线安全回到唯一营地 | 小组整理混乱的研究站记录，提交有证据的路线结论 |
| 1 分类 | 对照三项观察特征选脚印；取得路线起点 SUN | 比较四张批次档案卡；取得 R2 观察笔记 |
| 2 定位 | 从 SUN 按混序路线条在六地点未连线地图画路；取得 PINE SIGN | 只用 R2 笔记匹配足迹；取得 RIDGE 地区 |
| 3 合作 | 合并玩家手中的物资条件，选纸质补给卡；获得检查点代号 | 角色卡合并地点约束；确定观察区域 |
| 4 排序 | 查已给路标表，得最后路线与入口特征 | 按明示规则排时间条，形成路线记录 |
| 5 证实 | 用脚印、路线和入口条件选唯一营地卡 | 填观察结论与证据，教师核对后展示结局 |

**制品设计：**H02 玩家包为脚印/观察、混序路线条、六地点未连线纸地图、分持补给条件、路标表、候选营地；Host Guide 含成人交付的欢迎卡，并标注每张卡何时发、唯一营地答案和跳关后需补交的代号。C02 每组一套纸质档案页：批次卡、R1–R4 观察笔记、脚印特征、分角色地点条件、时间条、研究结论单；Teacher Guide 列组数复制方式、证据核对、角色合并和简短复盘。两版各有 A4/US Letter，灰度区分靠轮廓与编号。

**设计边界：**这是虚构故事，不声称恐龙知识教学或科学准确性；不要求野外搜集、触摸/食用植物、真实露营或危险移动。家庭的“找路”与课堂的“整理证据”要保持不同成就感。制作时先固定唯一营地/区域和约束表，再写旁白、三级提示与答案。

**视觉/交互制作规格：**封面以小恐龙、足迹和安全营地为三层纸片，不画危险追逐；网页卡片突出“找路”，课堂细节页再展示“整理档案”的差异。脚印至少靠脚趾数、脚跟轮廓和缺口位置区分，不能仅凭绿色深浅。地图条有明显起止接口和字母，营地候选保留文字条件；研究站材料使用档案袋、时间条和证据单样式。第三关四个候选应为可裁开的独立图文卡：H02 补给包印一/两条背带与圆/三角标签，同时保留路标名和代号；C02 区域卡印圆/三角标记与一/两面旗，同时保留地区名。角色卡与前关结果依然分别提供条件，候选卡不得直接标出正确答案。插画为故事提示，关键信息仍以印刷清楚的卡表为准。

**家庭第二关纸地图规格：**H02 同页印六个未连线、各自有文字标记的地点 `SUN`、`FERN`、`RIVER`、`PINE SIGN`、`CAVE`、`ROCK`。纸条 D/B/E/C/A 保持混序，玩家用第一关的 SUN 起点，只按纸条端点在地图画线；A-B-C 到达 `PINE SIGN`，D-E 走到无路标的 `ROCK`。地点卡之间留铅笔画线空间，但不预连任一路径、也不把三张正确纸条预排在一起。地图下方原有路线顺序与路标填写线保持；玩家不剪纸也能完成。教师版 C02 的证据整理流程不使用这张家庭地图。

**课堂观察卡规格：**C02 第一关应有四张可独立比较的批次档案卡：A＝叶形印章/一点/MILO/R1，B＝叶形印章/两点/MILO/R2，C＝星形印章/两点/MILO/R3，D＝叶形印章/两点/TARO/R4。每张卡均印批次字母、封印轮廓、可数圆点、标题与记录号，图形旁再用文字标明封印与点数；不靠颜色判断，也不暴露“B 为正确”的成人答案。教师可裁卡分发，也可不剪、在整页上逐卡比较；剪开后记录号须仍在卡内。第一关唯一结果 R2 才能进入足迹描述。

**批次到足迹的真实交接：**C02 第二关印有 R1–R4 四条观察笔记，玩家必须用第一关得到的批次号选取一条，再对照四张足迹卡。R1＝三脚趾/尖脚跟/右缺口，R2＝三脚趾/圆脚跟/右缺口，R3＝两脚趾/圆脚跟/右缺口，R4＝三脚趾/圆脚跟/无缺口；只有 R2 对应正确的 RIDGE 足迹。其他笔记只作为真实的批次分支，不用于本次任务；教师不得提前口述 R2 的性状。

**内部制品进度：**C02 第一关现有上述四张图文批次档案卡；H02 第一关与 C02 第二关现有四张独立的线条足迹卡，以脚趾数、圆/尖脚跟、右侧缺口及文字重复编码线索；H02 第二关有六地点未连线纸地图。第三关 H02 有四张背带/标签图文补给卡，C02 有四张标记/旗帜图文区域卡，所需的路标名与地区名仍来自前关结果。成人/教师指南答案页各有可打印的家庭欢迎卡/研究站回信，确认最终答案后才给玩家。符号是虚构故事图形，不代表真实恐龙足迹。课堂批次的实体档案袋和更完整的美术地图插画仍未制作；两种纸张当前只有屏幕核查，需真人试玩与彩色/灰度实物打印。
