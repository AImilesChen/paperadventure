# Christmas / Winter｜圣诞与冬日主题设计蓝图

**状态：**H06/C06 已有先行蓝图与内部 PDF 初稿，尚待真人试玩与实物打印。**视觉：**纸艺礼物标签、运输路线、信件与雪地邮局。C06 目前生成中性 Winter 草稿；Christmas 课堂措辞可由成人明确选择后派生并复核，不另售为独立世界。

| | H06 Home — The Christmas Delivery Office | C06 Classroom — The Winter Gift Sorting Station |
|---|---|---|
| 任务 | 整理运输局最后一份虚构礼物投递清单 | 每组核对订单，完成分拣清单和模拟发车 |
| 1 标签 | 用图案和批次规则找出待修复的清单 | 查标签与批次，确定本组当班任务 |
| 2 配对 | 依纸上收件偏好匹配礼物卡与地址卡 | 按订单图标配礼物与目的地 |
| 3 合作排序 | 玩家分持时间与路线条件，合并得到唯一顺序 | 组员合并重量等级/时间条件，排装载次序 |
| 4 译留言 | 用字典读运输留言；获得最后一站与确认标记 | 查路线表验证投递顺序，获得最终留言 |
| 5 投递 | 核对清单、顺序与标记，领取纸质回信结局 | 填分拣证据单，核对后做纸上发车确认 |

**制品设计：**H06 玩家包包含批次标签、礼物/收件卡、分持时间/路线条件、字典、目的地、回信；Host Guide 管理线索顺序与可选成人奖励。C06 每组订单图、重量/时间规则、路线表、角色卡、分拣清单、发车卡；Teacher Guide 说明非整除人数分组、角色轮换、冬日/圣诞版的准确文件份数与答案。A4/US Letter 实物验证后才能锁页数。

**设计边界：**故事礼物均为纸卡，不要求真实礼物、交换或购买；避免根据儿童家庭经济状况、节日习惯作评价。重量和时间为给定图形等级或经验证的数值，不突然增加单位换算。文案选择由成人明确决定，不根据语言或所在地推断其信仰。

**视觉/交互制作规格：**封面用邮局、信件、纸礼物和路线呈现“帮忙投递”，不画消费清单或礼物价值等级。网页卡可保持冬日雪景，主题页明确 Home 的 Christmas 故事与 Classroom 可选 Winter 表达。打印礼物卡用图形+名称，重量/时间规则用文字+图示，顺序不靠颜色判读。C06 的冬日与圣诞封面/措辞分别出片，答案数据、文件版本与校验记录同步。

**内部制品进度：**H06/C06 第二关现有四张带图形与文字的纸礼物/物品卡，另有三张可配对的纸目的地卡；圆/方/三角及书/星/铃图形在灰度下仍有名称辅助。图形只是纸艺线稿，非最终插画。C06 目前只有中性 Winter PDF，Christmas 课堂措辞版仍未制作；两种纸张的图形可辨、剪卡体验与真人理解需实物验收。

**插画候选：**网页课堂故事使用 `public/assets/winter-classroom-v0.1.jpg`，本地留有高分辨率 PNG；原 `christmas.png` 保留给 Home 世界卡。两张都不是实际资料包封面，C06 Winter/Christmas 的正式打印版仍需各自制作与验收。来源见 `design-handoff/THEME_VISUAL_VARIANTS.md`。
