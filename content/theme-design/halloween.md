# Halloween｜万圣节主题设计蓝图

**状态：**H05/C05 已有设计方案和内部谜题内容源，打印资料包仍为待验收草稿。**视觉：**友好南瓜、纸灯与小屋；无惊吓、暴力或火焰操作。C05 先做中性秋日课堂草稿；若成人明确选择万圣节措辞，须从同一答案合同派生并重验，不另算第七世界。

| | H05 Home — The Missing Pumpkin Light | C05 Classroom — The Autumn Festival Crew |
|---|---|---|
| 任务 | 取回四枚纸质印记并按卷轴顺序点亮故事南瓜灯 | 每组完成四项纸上庆典准备，组合开场标记 |
| 1 信使 | 用邮戳与角色卡认出 Pip 的信；获得第一印记与地图入口 | 认邀请图案；获得本组任务和站点索引 |
| 2 地图 | 依接口规则修复庆典地图；获得第二印记和包裹批次 | 修地图；获得第一类安排证据 |
| 3 合作 | 玩家交换两个条件确定唯一包裹；获得第三印记与回信字典 | 合并角色条件，确定纸质装饰分配；获得第二类成果 |
| 4 回信 | 用字典读回信；获得第四印记与使用顺序 | 解释流程记录；获得准备标记与顺序 |
| 5 开场 | 依序组合四印记的值，翻开唯一结局 | 核对本组四类成果，完成开场图并由教师收尾 |

**制品设计：**H05 玩家包为信使候选、地图、分持包裹条件、四枚独立印记、字典、顺序卷轴与结局；Host Guide 含唯一答案及逐关补发印记。C05 每组任务/地图/分工卡、装饰、流程、开场图与记录单；Teacher Guide 给出组内成果清单、份数、提示及可选桌面/站点组织。A4/US Letter 均保持印记编号清楚。

**答案控制：**PRD §10.13 的 `5723` 是 H05 基础实例，用于验证四枚值与顺序能一致推导；不是让所有变体或 C05 共用的固定口令。实例化更改任何印记值时，结局、提示、跳关补件、指南一起重算。C05 采用独立的成果结构和参数，不把 H05 的四位口令简单换成班级人数。

**设计边界：**没有真实蜡烛、电路或锁具；不要求孩子在黑暗处寻找东西。秋日表达须在用户主动选择后生成，不按地区或语言自动推断节庆偏好。

**视觉/交互制作规格：**南瓜、纸灯与月亮采用明亮温和的纸艺造型，不用骷髅、血迹、惊吓脸或闪烁效果。网页卡先传达“友好庆典”，Home 成品四枚印记分别有形状、编号和字面名称；Classroom 的四类准备成果使用另一套图形体系，防止误用家庭口令。秋日变体可替换南瓜节庆措辞和配色，但地图、线索及答案合同仍由同一版本派生并重验。

**插画候选：**网页世界卡使用 `public/assets/halloween-friendly-v0.1.jpg`，本地留有高分辨率 PNG；这仍是概念图。H05 内部打印稿第二关有文字路线条与三格纸上庆典路线板，第五关有四枚可填数字、可由成人选择裁开的纸质印记；C05 的中性秋日第二关有两格路线板。成人/教师指南答案页各有纸质结局卡，仅在最终答案确认后分享。真正的地图图形、真人试玩与实物打印验收仍缺。来源与审查记录见 `design-handoff/THEME_VISUAL_VARIANTS.md`。

C05 中性秋日表达使用 `public/assets/autumn-classroom-v0.1.jpg` 概念图。当前内部打印草稿只有 Autumn 版；Halloween 课堂措辞仍待从同一内容与答案数据派生并单独校验，不能只替换插画便宣称完成。
