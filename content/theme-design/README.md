## 两个版本共同的制作合同

每个版本先产出**可验证的故事数据**：五关各有 `state_before`、叙事理由、`requires_facts/items`、玩家动作、唯一答案、`produces_facts/items`、`state_after`、后续 `consumers`；主要成果须被下一关或结局实际使用。谜题、提示、跳关补发成果和成人答案统一来自同一份答案数据；文案不能另造谜底。每关三级提示为观察方向、推理方向、完整解法。跳关时交付标准成果，故事仍可走通。

每个 Home 版本交付英文 Player Pack 与 Host Guide；每个 Classroom 版本交付英文分组 Player Pack 与 Teacher Guide。两者均需 A4 和 US Letter、彩色与灰度可读、明确页码与剪裁/摆放说明、无额外付费道具依赖。指南包含准备清单、每关答案、三级提示、跳关规则、预计组织方式与收尾。年龄段、人数、时长、阅读支持和打印页数在真实试玩及实物打印后填写，不在策划阶段编造对外承诺。

## 开发顺序与门槛

1. 先冻结本目录六份蓝图，核对故事分工、五关因果链、关卡成果与素材边界；任何改变商品内容的修改需回写蓝图。
2. 每个版本单独制作内容源、答案数据、玩家包与主持/教师指南，随后导出 A4 与 US Letter。不要用 Home 文件简单替换人数来制作 Classroom。
3. 自动检查五关引用、唯一答案、提示/跳关补发、PDF 完整性、文件版本和哈希；再由真实家庭/课堂试玩与纸张打印验证。发现歧义或裁切须修改并复测。
4. 版本依次经过 `planned → draft → internal_test → release_ready → published`。只有完成内容、素材权利、文案/许可、法律税费与交付审查的版本才可发布。Home 与 Classroom 状态分别管理。节庆视觉变体同属原版本，不虚增世界或商品。

**首发商品界限：**Celebration 只是免费完整样例候选；尚未最终指定或发布。其他已验收固定包拟按 Home US$9.99、Classroom US$14.99 一次性销售；新定制活动另为 Home US$14.99、Classroom US$19.99，不能把固定包描述为 AI 生成或可免费任意改写。所有销售开关维持关闭，直到相应版本和结账条件都通过。

五类商品的交付单位、修改次数和所有者已确认的使用范围、12 个月在线重新下载期限，见[首发商品权益与许可决策卡](../首发商品权益与许可决策卡_v0.1.md)。产品规则仍须经过正式条款及实施审核，不能直接视作已生效的消费者合同。
