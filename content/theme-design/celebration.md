# Celebration｜庆祝主题设计蓝图

**状态：**H01/C01 设计回查中；两版各有 v0.1 PDF 初稿，未完成真人试玩、纸张验收或发布。**视觉：**纸艺邀请信、温和的小狐狸信使、宝箱/徽章、旗帜与清晰路线；不以生日蛋糕暗示课堂版必须庆生。

| | H01 Home — The Missing Birthday Chest | C01 Classroom — The Adventure Club’s First Badge |
|---|---|---|
| 任务 | 小队从信件中找到成人保管的结局信封或可选奖励 | 每组完成入会任务，组合属于本组的纸质徽章 |
| 1 起点 | 对比邮戳和图案，认出狐狸来信；获得路线碎片 | 对比邀请卡，认出俱乐部入口；获得任务页 |
| 2 路线 | 按接缝规则拼地图；获得有效路线与目的地标志 | 拼队伍路线；获得角色信息包 |
| 3 合作 | 玩家各持一条属性，求交集确定礼物标签；获得解码符号表 | 组内角色交换条件，选装备卡；获得徽章部件 |
| 4 解释 | 用符号表读留言；获得宝箱识别条件和排列顺序 | 用前面资料读徽章排列规则；获得最终装配指令 |
| 5 收尾 | 路线、标签、顺序合并，指向唯一结局信封 | 组合徽章并填写小组成果，教师按答案表收尾 |

**制品设计：**H01 玩家包有信件候选、地图碎片、分角色标签线索、符号表、候选宝箱卡、结局信；Host Guide 含安全摆放表、桌面顺序交付替代方案和答案/提示。C01 每组有邀请、路线图、可合并角色卡、装备与徽章部件、成果卡；Teacher Guide 有每组份数、开场演示、缺席/人数变化分配、答案/提示和共享收尾。两版分别导出 A4/US Letter，不混用结局和答案。

**设计边界：**不要求真实宝箱、购买礼物或儿童生日信息；只使用成人确认地点，也可全程桌面玩。课堂不寻找个人生日礼物或家庭藏点。黑白印刷时形状、文字和编号仍能分辨。既有 PDF 依照 [试玩验收表](../庆祝主题_H01_C01_试玩与发布验收表_v0.1.md)复核；发现故事数据与 PDF 不一致先修稿再测。

**视觉/交互制作规格：**沿用全站浅蓝纸艺底色，庆祝色只做旗帜、邮戳与徽章的局部点缀。封面先看到狐狸递信和一条可辨的纸路线；H01 用包裹与信封作结局焦点，C01 用团队徽章作焦点。网页卡片只暗示故事，不出现可被误认作真实成品的 PDF 缩略图。打印卡的邮戳、耳朵数、圆点数、路线接口和徽章部件必须用文字/轮廓双重编码；装饰不能遮住答案字段。主卡、玩家页、指南使用同一编号与图形词汇。

**当前视觉实现：**H01 封面与网页 Home 故事使用单独生成的狐狸送信概念图 `public/assets/celebration-home-v0.1.jpg`；C01 使用单独生成的探险俱乐部徽章概念图 `public/assets/celebration-classroom-v0.1.jpg`，并在网站课堂故事中对应显示。概念图不承载题目答案，来源见 `design-handoff/THEME_VISUAL_VARIANTS.md`。两版第一关分别有三张狐狸/猫头鹰来信和指南针/星形邀请的图文候选卡，以轮廓、数量和文字共同编码；第二关都有打乱顺序的路线条和空白三格拼接板，供裁开摆放或原页编号；唯一可到达目标的路线均为 A-B-C，生成时自动验证。H01 第五关有四张可选择裁开的包裹卡，成人指南末页有可裁下的狐狸结局信，玩家页不提前揭晓信的内容；无需另购礼物或自备信封。C01 第五关有可直接书写、也可由教师沿外框裁下的黑白徽章模板。纸卡实际操作与彩色/灰度印刷效果仍待真人试玩和实物验收。
