# Forest｜森林主题设计蓝图

**状态：**H04/C04 已有先行蓝图与内部 PDF 初稿，尚待真人试玩和实物打印。**视觉：**树屋邮局、猫头鹰或原创邮差、邮戳、纸包裹与地图；使用虚构角色和地址。

| | H04 Home — The Forest Post Office Mystery | C04 Classroom — The Forest Postal Investigators |
|---|---|---|
| 任务 | 帮邮差找出一件包裹的正确故事收件人 | 小组修正错分档案，完成“包裹—收件人—证据”结论 |
| 1 选批次 | 比较邮戳、形状与日期符号；获得批次标记 | 用批次符号界定本组调查范围 |
| 2 排记录 | 按纸上规则排列记录条；获得候选投递区域 | 排列投递记录；缩小候选地址 |
| 3 合作认包裹 | 玩家分持属性，求交集；获得包裹和地址碎片 | 各角色持部分属性，合并确认包裹并记录依据 |
| 4 修地址 | 用地图与碎片解码；获得唯一收件标志和路线 | 将缺失地址段匹配地图标记；获得完整投递证据 |
| 5 投递 | 核对批次、地址、收件标志，交给虚构角色并读回信 | 填结论卡，教师按证据规则核对并收尾 |

**制品设计：**H04 包含邮戳/批次卡、记录条、分持条件、包裹候选、地址拼片、地图、收件角色与回信；Host Guide 包含顺序交付和完整解法。C04 每组独立档案袋、角色卡、证据记录、结论单；Teacher Guide 明确缺席时由谁接管必需卡、分组份数、答案与复盘。两版 A4/US Letter、灰度可读。

**设计边界：**不使用真实住宅地址、儿童姓名或“偷窃”指控；误投是可善意解决的记录问题。任何一张角色卡不能直接泄露完整答案；人数不足仍可合并卡片。先建立包裹—线索—地址唯一匹配表，再产生卡片和提示。

**视觉/交互制作规格：**树屋邮局和纸邮戳是世界识别物，绿色只作故事气氛，不作为邮件分类的唯一信号。网页主题卡显示“邮局与包裹”，避免盗窃/追捕画面。打印的批次标记兼用字母、图形与日期符号；地址均为虚构地图格，候选包裹用明显编号。课堂证据单预留“依据来自哪张卡”的位置，家庭回信用温和的角色感谢语收尾。

**第二关纸邮路规格：**H04 的邮路图印六个未连线地点 `POST OFFICE`、`BRIDGE`、`MOSS LANE`、`BLUE TREE`、`POND`、`NO MAILBOX`；C04 的调查图印五个未连线地点 `POST OFFICE`、`STONE PATH`、`TREEHOUSE ROW`、`POND`、`NO ROUTE`。地点名只来自虚构故事，不是真实地址。首关取得的批次 M2/R7 必须先筛选混序记录条，再按端点在地图画线；H04 的 A-B-C 到 BLUE TREE，C04 的 L1-L2 到 TREEHOUSE ROW，错误批次走向无投递点。地图不能预印正确路线，也不能只靠绿色辨路；原有路线顺序和地区/区域填写线保留，成人可不裁纸条。

**第三关包裹卡规格：**H04/C04 各印四张独立边框候选卡 A–D，保留各自区域、叶片数或条纹数、纸包轮廓及地址碎片/编码。H04 用可数叶形印记与圆/方纸包外框，C04 用可数横纹与圆角/方角外框；每个属性都同时印文字，不依赖绿色深浅。候选 C 只是唯一满足三张角色线索的结果，不能在图形或装饰中暗示正确答案。成人可裁开分发，也可让玩家在整页比较；裁开后每张卡须保留其片段编号。

**课堂结论页规格：**C04 第五关候选结论卡后另设两行独立证据记录，不预填正确答案。每行分别让小组写“线索页/关卡”“该页看到的事实”“事实支持结论的哪个字段”。两行须来自不同线索页；教师用指南核对事实与所选卡一致，并允许学生口述后由组员代写。家庭版仍用两条简短理由，不强制使用课堂证据表。这个纸面记录是解题与复盘工具，不收集学生身份或成绩。

**内部制品进度：**H04/C04 第一关各有四张图文邮戳卡：H04 以树叶/月亮轮廓、星数、星期和批次四重标记；C04 以圆/方轮廓、点数、星期和批次四重标记。所有图形旁都有完整文字标签，不依赖颜色。第二关分别有六地点/五地点未连线纸邮路图，和独立的混序路线条配合使用。第三关有上述四张图文包裹候选卡，第四关有四格虚构地址地图，每格重复地区、碎片和收件标志；可直接在完整页面上核对。课堂第五关按上方规格提供两条独立证据记录，成人/教师指南答案页各有只在确认结局后分享的独立纸质回信卡。实体档案袋尚未制作；回信及其它材料仍待真人试玩。A4/Letter 仅完成屏幕核查，未通过实物打印。
