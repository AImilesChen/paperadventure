## 2. 2026-10-09 可核查的成本参考

DeepSeek 官方当前列出的 `deepseek-flash` 峰时每百万输入 token US$0.30、输出 token US$1.20；离峰及命中缓存可更低。为避免低估，以下以**峰时、无缓存**计算。模型、时段及价格可能调整，发布前重查并以账单实测替代。来源：[DeepSeek 模型价格](https://api-docs.deepseek.com/quick_start/pricing/)。

香港 Stripe 标准公开价中，USD 结算卡交易为 **3.4% + US$0.30**，国际卡另加 **0.5%**，发生货币转换另加 **2%**；实际商户合同、支付方式、结算货币和税费须在该账户核对。Checkout 本身随 Payments 提供。来源：[Stripe 香港价格](https://stripe.com/en-hk/pricing)。这是商户成本模型，**不是**顾客结账税费。

| 税前售价 | USD 结算基础卡费示例 | 再计国际卡＋换汇的压力示例（5.9%＋$0.30） | 压力示例扣卡费后、尚未扣 AI/基础设施/客服 |
| ---: | ---: | ---: | ---: |
| $9.99 | $0.64 | $0.89 | $9.10 |
| $14.99 | $0.81 | $1.18 | $13.81 |

示例 AI 预算：一次完整流程若合计 120,000 输入、50,000 输出 token，则峰时无缓存费用约 `120000×0.30/1000000 + 50000×1.20/1000000 = US$0.096`；三次同等尝试约 US$0.288。**这只是敏感性算例**，不代表本产品的真实用量：当前真实 DeepSeek 测试在内容质量审核处失败，尚未取得每个成功交付活动的完整账单。固定包每次销售通常不重复调用生成模型；制作成本应作为内容制作与维护投入另记。

## 3. 每单核算模板与价格结论

`净贡献 = 不含代收税的商品收入 − Stripe/支付手续费 − AI（提案＋生成＋审核＋失败重试＋修订）− Cloudflare/R2/邮件可变费用 − 退款/争议预留 − 客服与人工修复成本`。税费应按实际法定义务配置和记录；不能把代收税款当净收入。对固定包另跟踪设计、编辑、图片、翻译/校对及后续更正的摊销。对免费样例单独计入下载带宽、客服和后续转化，不把它当作“零成本”。

每次私有测试记录：SKU、setting、模型版本、输入/输出 token、API 花费、尝试/审核失败次数、PDF 字节和文件下载次数；每月按真实订单汇总退款、支付费、税务费用与客服工时。严禁记录 API Key、完整用户故事设定或儿童个人信息到成本日志。价格复核时用 P50/P95 成功交付成本，而非只用首个成功样本。

**产品决定：维持四个已确认开发标价，不新增积分或订阅；UI 可按此定稿。** 但不声称这四价已通过真实毛利和全球税费审查。Stripe test 的任务是验证金额、税、Webhook、退款和权限；不能替代商户税务判断。Live 放行前需拿到真实成功生成成本、香港 Stripe 实际费率和销售地税务判断，再决定是否更改正式售价；若改变，须同步更新 PRD、目录、文案、结账快照和法律页版本。
