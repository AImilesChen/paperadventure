# Paper Adventure｜前四阶段开发与验收状态

更新：2026-10-09。这里的“四阶段”是当前执行顺序：① PRD 功能闭环，② 现成资料包，③ 定制生成与交付，④ 前端/UI 验收。代码存在、模拟测试通过、私有测试环境运行与对公众开放是四种不同状态。

| 阶段 | 已有可核查证据 | 仍未完成 |
| --- | --- | --- |
| 1. PRD 功能闭环 | 31 个英文预渲染页面、六主题目录、Home/Classroom 双路径、账户/订单/价格/法律页面与后端 API 代码已实现；[前端 CI](https://github.com/AImilesChen/paperadventure/actions/runs/37878985202)和[隔离 Worker 部署](https://github.com/AImilesChen/paperadventure/actions/runs/37878981256)通过。站点 API 已同域连接 D1 测试目录。 | 真实账户邮件、付款、税费、法律发布与公开下载仍未开启；正式 PRD 用户旅程未做端到端生产验收。 |
| 2. 现成资料包 | 六主题的 12 个 Home/Classroom 草稿场景生成 48 份基础 PDF，另有 8 份成人选择的课堂节庆措辞稿；[私有暂存工作流](https://github.com/AImilesChen/paperadventure/actions/runs/37879803078)校验并上传合计 56 份 PDF 至隔离 R2，在 D1 写入 12 条 `internal_test` 包记录和两套课堂节庆措辞的 8 条 `internal_test` 变体文件记录。变体有独立发布状态，公开目录保持未发布。 | 草稿尚未经过真人试玩、实体 A4/Letter 彩色与灰度打印、版权与最终内容签收；节庆措辞选择、订单快照和对应私有下载已具备代码及模拟测试，但尚未对公众放行。用户已表示目前无法安排试玩，此项暂缓，不视为通过。 |
| 3. 定制生成与交付 | 后端含提案、队列、结构/语义校验、玩家与成人 PDF、私有储存、失败/重试、一次局部修订和权限模型；无密钥模拟测试在 CI 通过。按用户最新选择接入 DeepSeek Responses API，并保留显式选择 OpenAI 的回退实现；[后端 CI](https://github.com/AImilesChen/paperadventure/actions/runs/37883541507)及[隔离 Worker 部署](https://github.com/AImilesChen/paperadventure/actions/runs/37883829841)通过。隔离 D1/R2/Queue 已接通，下载端校验真实 PDF 字节哈希。 | [私有 DeepSeek 冒烟测试](https://github.com/AImilesChen/paperadventure/actions/runs/37883884339)在凭据检查处停止：本仓库常见 DeepSeek Actions Secret 名称均未配置，两个相关 Cloudflare Worker 也无 DeepSeek Secret。真实模型输出、成本、失败率与云端生成到下载尚不能验证。全站账户邮件服务及 Stripe 也未接入，相关能力开关保持关闭。 |
| 4. 前端/UI 验收 | [自动浏览器 QA](https://github.com/AImilesChen/paperadventure/actions/runs/37882454300)检查 31 个桌面路由和 6 个移动页面，共 37 次，保存 12 张截图；标题、资源、页面错误、水平溢出、预览 noindex 与手机菜单键盘打开及 Esc 关闭均无失败。6 个代表路由在桌面与手机上经过 axe 扫描，严重和关键级问题为零；同时修复了低对比度文字和预览提示的地标语义。主站 [noindex 预览部署](https://github.com/AImilesChen/paperadventure/actions/runs/37878981293)通过。 | 截图仍须人工视觉复核；键盘全流程、屏幕阅读器、不同设备及错误/空状态的现场验收未完成。Codex 右侧浏览器控制服务仍启动失败。自动浏览器运行在隔离 CI，不操作用户电脑浏览器。 |

当前对外网站仍是**技术预览**。四阶段已取得代码、内容草稿、私有云资源和自动化验收证据；上表右栏事项没有完成前，不应宣称 PRD 功能全部上线或允许销售/公开下载。下一步优先找到或重新安全配置 DeepSeek 项目密钥并完成真实生成测试、账户邮件方案、截图人工复核及键盘/屏幕阅读器验收；Stripe、税费与消费者条款在付款放行前完成。
