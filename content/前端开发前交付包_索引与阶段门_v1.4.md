## 已消除的关键冲突

| 原混乱点 | 统一决定 |
| --- | --- |
| 五个还是六个主题、免费几个 | 当前共六主题。Celebration 是唯一指定免费主题，Home H01 与 Classroom C01 **两版均免费**；另五主题的现成版本在发布后分别按 Home/Classroom 售卖 |
| US$14.99 是什么 | 现成 Classroom 或定制 Home 各为 US$14.99，但交付、AI 和许可不同；现成 Home $9.99、定制 Classroom $19.99 |
| “未试玩”是否阻止用户下载试玩稿 | **不阻止**。先提供标记版本的完整免费试玩文件，再收集反馈；正式付费上架的审查独立进行 |
| 已有 PDF 是否等于成品销售 | 56 PDF、14 套表达是内部 v0.1 成套试玩稿；可用于完整一局和打印反馈，但不宣称已完成商业验收 |
| 有 `/en/account/` 是否等于有登录 | 不等于。真实邮箱验证和页头可发现的 `Sign in` 尚未启用；UI v1.4 明确设计该入口 |
| 香港个人账户、不公开地址与全球销售 | 可全球浏览并开发；不虚构实体或地址。欧美等可能要求商户地址披露的市场在找到合规安排前不能宣布付费销售已合规 |
| 税前美元价与结账总价 | 目录展示开发标价；实际 Checkout 显示适用税费和最终总额；Stripe Tax 不能替代税务登记/申报 |
| DeepSeek Key 已配是否等于生成上线 | Key 可从 GitHub Secret 读取；真实私有测试仍在故事质量审核失败，公开生成开关关闭 |

## 阶段门（只评价本阶段，不偷换成上线）

| 顺序 | 可交下一阶段的完成定义 | 当前核对 |
| --- | --- | --- |
| 1 PRD/产品 | 统一商品与免费边界、下载/账号/生成/售后路径、状态和验收合同，无相互冲突的决策表 | **本包已补齐开发决定**；旧源文件需以 v1.4 为准 |
| 2 定价 | SKU 和计费单位确定、税前/含税分开、成本模型可复算 | **开发基线已补齐**；真实 AI 单位成本和商户费用须在销售前复核 |
| 3 文案与合规 | 主要页面与错误文案可交前端；四页法律审阅正文及实际数据流/未决项齐全 | **可交前端的审阅稿已补齐**；商户披露、留存、税务、法定市场审核未通过，不能生效 |
| 4 UI 设计 | 选定风格、变量、素材、所有核心屏幕/状态/响应式/可访问性规则可交前端；关键视觉证据逐项复核 | **设计合同已补齐，现场视觉签收仍未通过**；旧截图仅覆盖预览态，缺登录/试玩下载真实态等复核 |
| 5 前端 | 按以上交付实现真实入口、免费试玩、账户、创建/订单等；桌面手机及异常流测试 | 现有 31 路由是预览基础，核心功能未完成 |
| 6 后端/Stripe test | 实际邮件、DeepSeek→PDF、私有下载、Webhook/税费在隔离环境闭环 | 部分代码/私有资源已有；真实生成 QA 和服务联调未通过 |
| 7 正式发布 | 内容/版权、商户/税费/法律、隐私与支付实测、支持运营和 SEO/统计放行 | 未开始公开售卖；当前仍是 noindex 技术预览 |

**下一件开发动作不应是 Stripe test。** 前端先实现清晰登录入口、免费 Celebration 两版完整下载和与状态对应的 UI；后端随后把真实邮件与生成接上。Stripe sandbox 只在产品路径能被用户走通后检验付款与授权。正式销售还须另外解除商户资料和法律税务缺口。
