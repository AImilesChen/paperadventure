# Home and Classroom discovery · 2026-10-09

The six visual themes are shared worlds, but each setting has its own story title, goal, clue sequence and guide. Visitors should never have to infer this from a generic theme card.

## Navigation and routes

- Header and mobile menu: **For home**, **For classrooms**, **How it works**, **Pricing**. Sign in/My adventures and Create an adventure stay as account/action controls. The free Celebration printable and All themes remain discoverable in page content and the footer instead of occupying primary navigation.
- `/en/for-home/`: six Home story cards and the Home Celebration download.
- `/en/for-classroom/`: six Classroom story cards and the Classroom Celebration download.
- `/en/themes/`: overview with an explicit Home/Classroom switch; Home is the initial view.
- Each theme detail link carries `?setting=home|classroom`, highlights that story first, and carries the same setting into custom creation.

## Homepage

The existing horizontal theme carousel gains two clear setting controls, each labelled **6 themes**. Switching changes story artwork where a setting-specific image exists, title, mission, link destination and free Celebration label. The lower Home/Classroom pathway cards lead to the matching six-theme catalog, not directly into a custom form.

## Product-state language

Celebration Home and Classroom are distinct free trial games when the API reports them published. The five other worlds are custom-story starting points until their fixed packs are released. The classroom path does not silently reuse Home story copy.

## Acceptance

Desktop and mobile navigation reveal both audiences. Each catalog route renders six cards with the matching variant copy. A Classroom catalog link opens the detail page with Classroom prioritized. Search, free download, custom creation, keyboard navigation and responsive checks remain green.
