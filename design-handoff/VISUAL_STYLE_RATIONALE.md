# Visual Style Rationale 与反模板约束

阶段：06-design。日期：2026-10-08。本文件是对三张**既有**概念图及已选实现的现状整理，非当时生成过程的原始记录。

## 三个方向的比较

| 方向 | 视觉概念与内容密度 | 适配性与取舍 |
| --- | --- | --- |
| [01 Story Atlas](concepts/01-story-atlas.jpg) | 地图式世界观、宏大的冒险场景，Hero 视觉占比高；主题卡承接在下方。 | 能表达探索感，但地图和道具较多，产品是什么、成人如何准备可打印材料需要更多文字支撑。 |
| [02 Storybook Theatre](concepts/02-storybook-theatre.jpg) | 剧场/绘本布景、狐狸角色、舞台式大图；版面更像故事展示。 | 亲子情绪强，但舞台框架可能让产品误解为在线戏剧或角色故事，材料与协作解谜不够直观。 |
| [03 Paper Adventure Workshop](concepts/03-paper-adventure-workshop-selected.jpg) | 浅蓝纸艺、文案与主图非对称并列，Hero 后直接出现横向主题长廊；图文密度较均衡。 | 更能同时容纳「纸上材料」「选现成世界」「自己生成」三条信息，已由用户在 2026-10-07 选定。 |

选定方向的目标是让欧美英语用户一眼知道这是成人组织的可打印故事冒险；插画负责情绪，网页真实文字负责产品事实、价格和可访问性。当前预览尚没有正式商品，因此不把未完成的 PDF、好评或即时交付表现为现货。

## 反通用 AI 模板约束表

| 模块 | 已选规则 | 验收点 |
| --- | --- | --- |
| 背景与文字 | 主背景浅蓝 `#d8f0fc`、文字深蓝 `#0d294f`；卡片可用暖白 | 全站不改回大片米白或紫蓝渐变 SaaS 底色；文字对比清楚。 |
| 强调与动作 | 朱红 `#ec4d35` 用于主要动作和少量视觉重点 | 首页主 CTA 最醒目；主题卡不并排摆六个同级红色购买按钮。 |
| 字体 | Nunito Sans 为主体，Bree Serif 仅作世界名称点缀 | 禁用 Inter/Roboto/Arial 作为品牌默认字体；英文长标题不截断。 |
| Hero | 左文案右纸艺场景，首屏仅一个主要创建动作 | 主题长廊在其后；不用居中口号加三张通用功能卡开场。 |
| 图像 | 同一明亮绘本/纸艺风格；主题插画和真实 PDF 样张区分 | 插画不烘焙商品标题、价格、评分；不把装饰图冒充可下载游戏。 |
| 卡片与图标 | 故事世界大图卡、Phosphor 功能图标、自制纸飞机品牌标 | 图标风格一致；卡片密度以真实视口而非长海报决定。 |
| 移动端 | 390 px 为基准，兼顾 360/430 px；部分露出下一卡 | 整页无横向溢出；长廊可触摸滑动，CTA 与说明仍可读。 |
| 文案 | PRD、英文文案稿、定价与合规约束优先于效果图 | 不用虚构评价/销量/保证适龄或尚未上线的下载承诺。 |

**Design review status:** 方向 03、首页桌面和部分移动页面已有截图及代码 QA；全路由手机与关键状态的设计截图尚未齐备。完整视觉验收仍需浏览器恢复后执行。
